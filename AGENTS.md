# Repository Guidelines

The skill development standard for this repository is maintained in a single place: [CLAUDE.md](CLAUDE.md). Read it before changing anything under `skills/` or the root connector metadata, and follow the step-by-step procedure in [.claude/skills/skill-development/SKILL.md](.claude/skills/skill-development/SKILL.md). The CI workflow `.github/workflows/skills-standard.yml` enforces the mechanically checkable rules.
