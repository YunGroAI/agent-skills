# 场景写作模板

不同类型的文章，情绪来源和读者期待完全不同。确定选题后先选一个模板，
它决定开场方式、结构骨架、情绪主峰放在哪、需要向用户问什么素材。
模板只给骨架，血肉（细节、原话、数字）必须来自 [voice.md](voice.md) 的素材采访。

## 怎么选

| 用户要写的 | 模板 | 主目标常见值 |
|---|---|---|
| 自己或团队的一段经历、踩坑、复盘 | 经历复盘 | `trust` / `reach` |
| 教读者做成一件事 | 方法干货 | `follower_growth` / `reach` |
| 对一件事、一个热点表态 | 观点评论 | `reach` |
| 讲客户/用户/员工的故事 | 人物案例 | `trust` / `leads` |
| 介绍产品、服务、课程并促成行动 | 产品种草 | `leads` |
| 活动、招募、通知 | 活动通知 | `leads` |
| 节日、纪念日、年终、感谢 | 情感随笔 | `trust` |

一篇只用一个模板。混用（比如前半篇讲故事、后半篇硬转卖货）是生硬感的常见来源；
确需转化时，用人物案例或经历复盘模板，转化放在结尾自然带出。

## 经历复盘

- **开场**：直接切进最狼狈或最关键的那一刻（时间 + 地点 + 一句原话）。
- **骨架**：那一刻 → 倒回去讲怎么走到这一步 → 做错了什么（具体到动作）→
  转折：谁/什么让我改变 → 现在的做法 → 留给读者的一句话。
- **情绪主峰**：转折处。前面的狼狈写得越实，这里越有力。
- **要问的素材**：最难受的瞬间、当时的原话、具体损失、改变的契机、前后对比的数字。
- **避免**：把复盘写成「三点经验总结」；结尾升华成人生道理。

## 方法干货

- **开场**：一个读者熟悉的失败场景，或一个反常识的结果。
- **骨架**：为什么老办法不行（说到痛处）→ 新做法的核心一句话 → 分步演示
  （每步配一个真实例子或截图）→ 常见翻车点 → 今天就能做的第一步。
- **情绪主峰**：「原来如此」的顿悟处，通常是新做法的核心那句。
- **要问的素材**：作者亲自用过的实例、前后对比、读者最常问的问题、最容易做错的一步。
- **避免**：「首先其次最后」的说明书腔；每一步都只有道理没有例子。

## 观点评论

- **开场**：一句明确的立场，或一个让人意外的事实。
- **骨架**：亮出立场 → 大家通常怎么看 → 我为什么不同意（证据 1、2）→
  承认对方有道理的部分 → 我的结论和适用边界。
- **情绪主峰**：最有力的那条证据，或最能引起共鸣的一句判断。
- **要问的素材**：作者真实的立场和理由、亲历或一手信息、不同意见者的原话。
- **避免**：「一方面…另一方面…」的骑墙；为了显得平衡而没有观点；伪造热点和数据。

## 人物案例

- **开场**：主人公最有画面感的一个瞬间，不先介绍背景。
- **骨架**：瞬间 → 他是谁、原来的处境 → 遇到的难题（越具体越好）→
  他做了什么（我们在其中起了什么作用）→ 变化（数字或原话）→ 他现在怎么说。
- **情绪主峰**：难题最尖锐的时刻，或主人公说出的最真实的一句话。
- **要问的素材**：主人公原话、可公开的身份信息、前后对比、一个具体的转折事件。
- **避免**：把主人公写成广告代言人；所有功劳都归给产品；未经同意公开隐私。

## 产品种草

- **开场**：读者的一个具体麻烦，不是产品名。
- **骨架**：麻烦 → 试过的办法为什么不行 → 发现这个东西的经过 → 真实用法
  （含一个缺点或不适合的人）→ 适合谁 → 怎么获取。
- **情绪主峰**：「终于解决了」的那个具体时刻。
- **要问的素材**：真实使用场景、用户反馈原话、价格与获取方式、不适合的人群。
- **避免**：参数罗列；只说优点；广告法极限词（最、第一、顶级、100% 等）和效果承诺。

## 活动通知

- **开场**：一句话说清这是什么、跟谁有关、截止时间。
- **骨架**：一句话要点 → 为什么值得来（具体收获，不写「干货满满」）→
  时间地点方式 → 怎么报名 → 一句来自往期参与者的真实反馈（如有）。
- **情绪主峰**：不需要强情绪，重点是信息清楚、门槛低。
- **要问的素材**：时间、地点、名额、费用、报名方式、往期反馈。
- **避免**：把通知写成长文；关键信息埋在文末。

## 情感随笔

- **开场**：一个小物件、一个小动作、一句话，越小越好。
- **骨架**：小切口 → 由它想起的一段往事 → 当时没说出口的话 → 现在的理解 →
  回到开头那个小物件。
- **情绪主峰**：「没说出口的话」那一段。
- **要问的素材**：具体的物件、日期、对话、作者当时的心情、现在的心情。
- **避免**：大词（感恩、成长、蜕变）；排比抒情；为了感动而编造情节。
