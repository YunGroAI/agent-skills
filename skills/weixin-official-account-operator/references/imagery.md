# 配图规划

配图不是写完文章再补的装饰，而是和提纲一起定的「视觉脚本」。
图要同时满足两件事：**内容上对应所在段落的语义**，**观感上属于同一套主题调性**。
两张好看但风格不统一的图，比一张克制的图更伤整体质感。

## 何时进入本文件

- 提纲确定、准备生成配图或封面之前。
- 用户提到配图、封面、插图、「图要好看」「图和文不搭」。
- 主题已按 [themes.md](themes.md) 定下来之后（主题未定不要先出图）。

## 第一步：写配图脚本

按提纲逐段标注，先出这张表再生成任何一张图：

| 位置 | 角色 | 要传达的一件事 | 画面主体 | 与主题的关系 |
|---|---|---|---|---|
| 封面 | 2.35:1 横图 | 标题的情绪或冲突 | 人物/器物/场景，避免文字 | 定调整篇的第一印象 |
| 首屏后 | 场景锚点 | 让读者「看见」开头那个场景 | 具体动作，非概念图 | 主色同一色系 |
| 中段 | 论证配图 | 转折点或方法可视化 | 对照、流程、细节特写 | 用强调色点缀 |
| 收尾前 | 情绪收束 | 给一个可以停下来的画面 | 留白、远景、余味 | 降饱和，别抢 CTA |

篇幅建议：正文每 400–600 字一张图，长文 3–5 张，短文 1–2 张。
**不要为了填满用图**：一段话已经说清的内容配一张同义反复的图，只会拖慢阅读。

## 第二步：每类图的画面要求

- **封面**：横构图、主体占画面 1/3 以上、留一处放标题的安全区；
  高对比、一眼可辨识，缩略到 1/5 仍能看清主体。不要用密集文字排版当封面。
- **场景图**：有人、有动作、有具体环境细节（工位、厨房、地铁、会议室），
  不要「抽象科技光效 + 齿轮」这类万能图。
- **论证图**：用对照、拆解、步骤感表达；如生成不可控，改用正文里的
  `:::card` 结论卡或 `:::stat` 数字块替代，不要硬凑一张说不清的图。
- **收尾图**：低饱和、留白多，和 CTA 之间留出呼吸感。

## 第三步：主题调性对应表

主题（见 [themes.md](themes.md)）决定色调与质感，写 prompt 时逐条带上：

| 主题 | 色调 | 质感与构图 | 典型题材 |
|---|---|---|---|
| `professional` | 深蓝 + 中性灰 | 冷静、对称、办公真实场景 | 行业解读、方法论 |
| `tech` | 冷蓝 + 深色底 | 几何、光感、抽象但克制 | AI/技术解读、产品发布 |
| `warm` | 暖橙棕 + 米白 | 自然光、人物近景、生活质感 | 人物故事、品牌叙事 |
| `fresh` | 青绿 + 白 | 干净、明亮、留白多 | 清单干货、效率技巧 |
| `magazine` | 暗红 + 黑白 | 强对比、纪实、粗颗粒 | 深度长文、观点评论 |
| `academic` | 灰蓝 + 白 | 简洁图示感、数据感 | 教程、数据报告 |
| `vibrant` | 高饱和红橙 | 动感、满构图、强对比 | 活动、新品、福利 |
| `oriental` | 墨绿 + 朱砂 | 留白、水墨、器物静物 | 传统文化、节气、文旅 |

同一篇内所有图使用同一套「色调 + 质感 + 光线 + 镜头」描述，
只让画面主体变化。中途换风格等于换了一篇稿子。

## 第四步：prompt 写法

一次只描述一张图，按这个顺序写，避免堆形容词：

```
[主体 + 动作/状态] ，[环境/场景] ，[镜头与构图：特写/中景/横构图 2.35:1] ，
[光线：自然侧光/柔光/冷光] ，[色调：<主题对应色调>] ，[质感：<主题对应质感>] ，
no text, no letters, no logos, no watermarks
```

要点：

- **图上不要出现文字**：生成模型写中文几乎必然乱码，`no text` 必须写进每张 prompt。
- 需要表达数字或文字信息时，用正文的 `:::stat` 数字块或 `:::card` 结论卡，不靠图。
- 不指定真实品牌、真实人物姓名、在世人物肖像；不生成与事实相关的纪实场景当作真实照片。
- 一次生成 1–2 张候选，看完再定，不要一次生成十几张盲选。

## 第五步：落地链路

1. 生成后串行跑处理脚本（**必须串行**，并发会因输出文件名按秒生成而互相覆盖）：

   ```bash
   PY=python3   # 没有 Pillow 时先 python3 -m pip install pillow
   $PY scripts/prepare_image.py 原始图1.png 原始图2.png -o ./wx_images
   $PY scripts/prepare_image.py ./wx_images --check-only
   ```

2. 取得公网 HTTPS 地址后：正文图调 `weixin_oa_upload_content_image`（拿 mmbiz URL），
   封面调 `weixin_oa_add_material`（拿 `media_id`，写入 `thumb_media_id`）。全程带 `connection_id`。
3. 图片插在**语义对应**的段落之后，按配图脚本的位置放，不要堆开头或全放文末。
4. 图注写图里没有的信息（出处、补充、一句点评），不重复正文原句；
   `![说明](url)` 的说明文字会同时作为 alt 和图注。
5. 图片链路不通时的兜底与错误码判定见 [publishing.md](publishing.md)；
   走手动通道就要如实说明图没有进草稿。

## 出稿前自检

- [ ] 每图都对应配图脚本里的一行，没有「顺手加的图」。
- [ ] 缩略图状态下封面主体仍可辨认，标题区没被主体压住。
- [ ] 全套图的色调、光线、镜头语言一致，与所选主题相符。
- [ ] 图上无文字、无水印、无 logo、无真实品牌与人物。
- [ ] 图注不是正文的复述；alt 有意义。
- [ ] 已串行跑过 `prepare_image.py` 并通过 `--check-only`。
