# 人味写作：口吻、素材与情绪

AI 味不是用错了几个词，而是三件事缺位：**没有一个具体的人在说话、没有只属于这篇的真实细节、
没有情绪的起伏**。换词只能治标；先把这三件事补上，再谈节奏和措辞。

- 写作流程与节奏：[editorial.md](editorial.md)；场景模板：[templates.md](templates.md)
- 对标他人写法：[benchmarking.md](benchmarking.md)

## 何时进入本文件

- 准备动笔前（建口吻卡、采访素材），每篇必走。
- 用户说文章「AI 味重」「生硬」「像通稿」「没感情」「不像我写的」。
- 用户要求续写、扩写、缩写、润色、改口吻或仿写某篇文章。

## 1. 口吻卡：先定「谁在说话」

每篇动笔前用一张口吻卡锁定说话的人。来源按优先级：

1. **账号历史文章**：读 1–3 篇该号表现好的文章（`weixin_oa_get_published_article`），
   从原文里提取下表各项——这是最像「本人」的依据。
2. **用户给的样文**：用户自己写的朋友圈、旧稿、喜欢的作者。
3. **对话里问**：前两项都没有时，只问三个问题：「你在号里怎么自称？」「希望读者觉得你像
   朋友、老师、同行还是记者？」「有没有你绝对不会说的话？」

| 项 | 要锁定什么 | 示例 |
|---|---|---|
| 身份 | 作者是谁、站在什么位置说话 | 做了 8 年 HR 的部门负责人，不是「专家」 |
| 自称 / 称呼读者 | 我 / 我们 / 笔者；你 / 大家 / 各位 | 「我」+「你」，不用「笔者」「小伙伴们」 |
| 距离感 | 朋友聊天 / 同行交流 / 老师讲课 / 记者报道 | 同行交流：可以吐槽，不说教 |
| 情绪浓度 | 克制 / 温和 / 热烈；幽默程度 | 克制，偶尔自嘲 |
| 句子习惯 | 长短、口头禅、方言、标点偏好 | 短句多，爱用「说白了」，少用感叹号 |
| 禁用 | 不会说的话、不碰的话题 | 不喊口号，不用「家人们」 |

口吻卡用三五行写出来，与主题简报一起给用户确认一次。服务端不保存它；用户同意时可以存成
本地文件，下次直接复用。**没有口吻卡就动笔，结果一定是「平均的 AI 腔」。**

## 2. 素材采访：真实细节从用户那里问出来

情绪来自细节，细节只能来自真实经历。Agent 不在场，所以要像记者一样问。
主题简报确认后，按主题挑 3–5 个问题一次问完（不要逐个挤牙膏）：

- **场景**：这件事发生在什么时候、什么地方？当时你在做什么？
- **冲突**：最卡的是哪一刻？谁说了什么让你印象最深（原话）？
- **感受**：那一刻你心里第一个念头是什么？后来有没有改变看法？
- **代价**：为此付出了什么——时间、钱、关系、面子？
- **数字**：有没有能说出口的具体数字（花了几天、改了几版、多少人）？
- **反常识**：做完之后，你发现哪件事和你原来想的不一样？

用户的回答哪怕很碎，也比 Agent 编的「完整故事」有力得多。规则：

- 用户给的原话、细节、数字**原样保留**，只做最小润色；不替用户虚构经历、对话或数据。
- 用户确实没有素材时，明说「这篇只能写成观点/方法文，情绪会偏弱」，并改用公开案例
  （注明来源）或「读者常见处境」的写法，不假装是亲身经历。
- 涉及他人的细节先确认可以公开，必要时模糊化身份。

## 3. 情绪表达：让读者「感到」而不是「被告知」

| 技法 | 生硬写法 | 有人味的写法 |
|---|---|---|
| 写动作不写形容词 | 我非常焦虑。 | 那晚我把方案开了又关，关了又开，到两点还没睡。 |
| 用原话代替转述 | 领导对结果不太满意。 | 领导看完只说了一句：「你自己读一遍。」 |
| 写身体与感官 | 会议气氛很紧张。 | 会议室没人说话，空调声突然变得很响。 |
| 暴露内心独白 | 我意识到问题所在。 | 我心里咯噔一下：坏了，问题出在我自己身上。 |
| 承认不完美 | 这个方法效果显著。 | 这招不是每次都灵，上个月就砸过一次。 |
| 具体到一个人 | 很多职场人都有这个困扰。 | 我们组的小林，入职三个月，每周五都在改周报。 |
| 留白不说满 | 这件事让我深刻认识到坚持的重要性。 | 后来那份周报，我又改了四遍。 |

情绪安排的原则：

- **先事后情**：先把场景写实，情绪让读者自己生出来；直接写「我很感动」等于没写。
- **一篇一个情绪主峰**：放在转折处，前面铺垫、后面收住，不要每段都在煽情。
- **克制比夸张有力**：一句平静的陈述，往往比三个感叹号更能打动人。
- **允许态度**：有立场、有偏好、有不同意，读者才觉得对面是个人；但态度要有依据。
- **自嘲与幽默**：口吻卡允许时，用在作者自己身上，不拿读者和他人开涮。

## 4. AI 味清单：写完逐项排查

`lint_article.py` 能抓到其中一部分，其余靠 Agent 自查和朗读。

| AI 味特征 | 典型句式 | 怎么改 |
|---|---|---|
| 万能开场 | 在这个信息爆炸的时代… / 你是否也曾… | 第一句直接进入一个具体时刻 |
| 机械连接词 | 首先…其次…再次…最后… / 此外 / 总而言之 | 删掉序号词，用内容本身的因果推进 |
| 「不是…而是…」滥用 | 这不是 X，而是 Y（全文出现多次） | 全文最多留一处，其余直接说结论 |
| 对仗排比三连 | 它不仅…更是…还是… / 让 A 更 A，让 B 更 B | 拆掉，留最有分量的那一个 |
| 空洞升华 | 这不仅是…更是一种态度 / 值得我们每个人深思 | 换成一个具体的下一步，或干脆删掉 |
| 总结式结尾 | 总之 / 希望本文对你有所帮助 / 让我们一起… | 结尾回到开头的场景，或抛一个具体问题 |
| 假设性提问轰炸 | 你是不是…？你有没有…？你是否…？ | 全文提问控制在关键处一两次 |
| 均匀的段落 | 每段一样长、都是「观点+解释+总结」 | 长短段交错，允许一句话成段 |
| 面面俱到 | 一方面…另一方面…当然也要看到… | 选一个立场说透，反面意见一句带过 |
| 符号堆砌 | 大量破折号、冒号小标题、emoji、加粗 | 破折号全文少于 3 处，加粗只给真正要截图的句子 |
| 抽象名词链 | 提升效率、优化体验、赋能业务 | 说清楚谁、做了什么、变成了什么样 |
| 伪造亲历 | 「我身边一个朋友…」（其实是编的） | 没有真实素材就不用第一人称讲故事 |

## 5. 去 AI 味改稿 SOP

初稿写完后按顺序过五遍，每遍只盯一件事（一遍改所有问题，最后什么都没改好）：

1. **结构遍**：删掉开头的铺垫段和结尾的总结段，看文章是否更好——通常是。
2. **口吻遍**：对照口吻卡，把不像这个人会说的话改掉；书面词换口语词
   （进行沟通 → 聊、予以解决 → 解决、具有 → 有）。
3. **细节遍**：每个抽象判断旁边找一个具体的人、事、数字或原话；找不到就删掉这个判断。
4. **节奏遍**：长短句交错，允许单句成段；把三连排比拆开；同一种句式不连用三次。
5. **朗读遍**：读出声，卡壳的地方就地改；读起来像「念稿」的段落重写成「讲给朋友听」。

改完跑 `scripts/build_article.py`（内含体检）。体检通过不等于没有 AI 味——
它只能抓模式，最终以「像不像这个人在说话」为准。

## 6. 局部改写指令

用户只想改一部分时，不重写全文。常见指令的做法：

| 指令 | 做法 | 注意 |
|---|---|---|
| 润色 | 只按第 4 节清单改措辞和节奏，不动结构和观点 | 改完列出改了哪几类问题 |
| 续写 | 先读完前文，沿用同一口吻、同一情绪走向往下写 | 不重复前文已说过的观点 |
| 扩写 | 补细节、例子、原话或步骤，不补形容词和空话 | 素材不够就先问用户要 |
| 缩写 | 先删铺垫和重复，再合并例子，最后才压句子 | 保留原话、数字和情绪主峰 |
| 换口吻 | 换口吻卡，重写句式与自称，事实和结构不变 | 先给一段样例让用户确认 |
| 仿写 | 按 [benchmarking.md](benchmarking.md) 拆技法，只借结构与节奏 | 不沿用原文的事实、案例和金句 |
| 改标题 | 按 [editorial.md](editorial.md) 第 4 节出候选并跑 `score_title.py` | 标题承诺必须在正文兑现 |

每次局部改写都给出改动前后对照（至少关键几处），让用户能判断改得对不对。
